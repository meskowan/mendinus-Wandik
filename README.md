# Mendinus Wandik — Personal Website

Website profil pribadi dengan identitas brand **aplannymw**. Dibuat menggunakan HTML, CSS, dan JavaScript biasa sehingga mudah diedit dan langsung bisa di-host di GitHub Pages.

## Isi folder
- `index.html` — konten dan struktur website
- `style.css` — desain responsif
- `script.js` — menu mobile dan tahun otomatis
- `assets/logo-aplannymw.svg` — logo SVG

## Cara upload ke GitHub
1. Login ke [GitHub](https://github.com/) lalu pilih **New repository**.
2. Beri nama repository, misalnya `mendinus-wandik`, lalu pilih **Public**.
3. Upload semua isi folder ZIP ini (bukan file ZIP-nya saja) ke repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
7. Tunggu beberapa menit. GitHub akan menampilkan alamat website di bagian Pages.

## Bagian yang perlu kamu sesuaikan
- Ganti `emailkamu@example.com` pada `index.html` dengan email aktif.
- Tambahkan tautan GitHub, Instagram, atau media sosial milikmu bila ingin ditampilkan.
- Ganti deskripsi keahlian dan contoh proyek dengan pengalaman serta karya yang benar-benar kamu miliki.
- Jika ada foto profil, letakkan di folder `assets` lalu tambahkan ke `index.html`.

## Catatan
Website ini tidak membutuhkan proses build atau framework. Cukup upload file ke repository dan aktifkan GitHub Pages.
