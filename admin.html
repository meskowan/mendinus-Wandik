Dashboard Admin.

Kelola proyek yang tampil pada website portofolio Mendinus Wandik.

Catatan keamanan: halaman ini tidak memakai password bawaan yang ditanam di website. Kamu menghubungkan GitHub menggunakan fine-grained Personal Access Token yang hanya disimpan sementara di tab browser. Jangan bagikan token kepada siapa pun. Berikan akses hanya ke repository portofolio ini dengan izin Contents: Read and write.

1. Hubungkan repository GitHub

Isi pemilik repository, nama repository, branch, dan token GitHub kamu.

Belum terhubung.

Bagaimana membuat token GitHub?
  1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Pilih Generate new token, batasi akses ke repository portofolio ini saja.
  3. Pada Repository permissions, set Contents menjadi Read and write.
  4. Buat token, salin, lalu tempel di kolom token di atas. Token hanya disimpan di session browser selama tab aktif.

Jangan aktifkan izin yang tidak diperlukan. Jika token terlanjur terbuka atau dibagikan, cabut token tersebut dari GitHub.

2. Tambahkan / edit proyek

Hubungkan GitHub terlebih dahulu. Gambar akan disimpan di repository dan daftar proyek diperbarui agar terlihat oleh pengunjung.

3. Proyek yang sudah diterbitkan

Edit atau hapus proyek dari repository.

Hubungkan GitHub untuk melihat daftar proyek.
